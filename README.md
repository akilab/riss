# riss

情報処理安全確保支援士「科目A-1」の技術基礎を、操作しながら学ぶ静的Web教材です。

## 確認方法

リポジトリを取得し、`index.html`をブラウザで開いてください。インストールやビルドは不要です。HTML・CSS・Vanilla JavaScriptのみで動作します。

現在の教材はLesson 01「進数・bit」、Lesson 02「論理演算」、Lesson 03「論理回路・フリップフロップ」、Lesson 04「CPU・命令実行」、Lesson 05「メモリ・キャッシュ」です。ほかの教材は目次上で「準備中」と表示します。

Lesson 02は5種類の論理演算と真理値表、Lesson 03は半加算器、NOR型RSラッチ、立上り型Dフリップフロップを操作できます。RSラッチは交差した戻り線とOR→NOTの計算を表示し、セット・保持・リセット・禁止入力を比較できます。動く回路図とタイミングチャートはSVGで描画し、操作はキーボードでも使えるHTMLボタンで行います。説明用のSVG素材は`assets/images/`に保存しています。

Lesson 04は取出し・解読・実行を1段階ずつ進め、PC・IR・ACCと主記憶の変化をSVGで確認できます。入力値は0〜99で変更できます。

Lesson 05はキャッシュのヒット・ミスと2枠でのコピーの入替えをSVGで確認できます。場所と中身を分けて表示し、架空の時間単位で読出しの待ち時間を比較します。

進捗と確認問題の直近成績は`localStorage`の`riss.a1.progress.v1`に保存します。保存はブラウザ・公開元ごとで、端末間の同期はありません。`file://`での保存の扱いはブラウザによって異なります。トップと教材で保存を共有する確認には、ローカルHTTPサーバーを使用してください。

保存が禁止されている場合や保存データを読み込めない場合も、Labと確認問題は利用できます。JavaScript無効時は本文を閲覧できます。

## GitHub Pages

GitHubのSettings → Pagesで公開元のブランチとルートディレクトリを指定できます。成果物のビルドは不要です。リポジトリ名を含むサブパスでも動くよう、リンクとアセットは相対パスにしています。

この作業では公開設定の変更やデプロイは行っていません。

## 教材を追加するとき

1. `lessons/01-number-bit.html`を基に、学習目標・本文・Lab・問題・完了・前後ナビの構成を維持してHTMLを追加する。
2. `js/curriculum.js`の教材情報と公開パス、`index.html`の静的目次・公開数・進捗の初期表示を更新する。保存済み進捗に使う教材IDは変更しない。
3. Lab固有処理は`js/labs/`に置き、必要なページだけで読み込む。
4. 確認問題を変更したら`data-quiz-version`を更新する。各フォームの`data-answer`と`data-explanation`を設定する。
5. 進捗保存・相対リンク・狭い画面・キーボード・入力エラーを確認する。

仕様は`docs/SPEC.md`、共通UIと操作の方針は`docs/DESIGN.md`を参照してください。
