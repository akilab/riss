# 情報処理安全確保支援士 科目A-1 学習サイト SPEC

## 1. プロジェクト概要

情報処理安全確保支援士試験の「科目A-1」対策を目的とした、Webベースの学習教材を開発する。

対象者は、情報セキュリティマネジメント試験には合格しているが、基本情報技術者試験・応用情報技術者試験は未受験または未合格の学習者を想定する。

そのため、セキュリティ知識そのものよりも、以下のようなコンピュータサイエンス・IT基礎技術の理解を重点的に補強する。

- 進数・bit・論理演算
- コンピュータ構成
- CPU・メモリ
- 論理回路・フリップフロップ
- OS
- ネットワーク
- データベース
- アルゴリズム・データ構造
- システム性能・信頼性
- 暗号・認証
- Web基礎・Webセキュリティ

教材は GitHub Pages で公開する。

---

## 2. 教材の目的

単なる暗記教材ではなく、

「仕組みを理解してから試験問題を解けるようになる」

ことを目標とする。

特に、文章や静止画だけでは理解しにくい分野については、

HTML + CSS + JavaScript

を用いたインタラクティブ教材として実装する。

学習者が何度も操作しながら、

- 予想する
- 動かす
- 結果を見る
- 理由を理解する
- 問題を解く

という流れで理解を深められる教材とする。

---

## 3. 想定学習者

以下を主な対象とする。

- 情報セキュリティマネジメント試験合格程度の知識を持つ
- セキュリティ用語にはある程度慣れている
- 基本情報技術者試験の体系的な学習経験がない
- 応用情報技術者試験も未経験
- 数学・進数・論理回路・アルゴリズムなどに苦手意識がある可能性が高い
- ネットワークについては用語は知っていても、内部動作までは理解していない可能性がある

説明は初学者向けとし、前提知識を要求しすぎない。

## 5. 教育方針

各ページは原則として以下の流れで構成する。

1. このページで学ぶこと
2. まずイメージを掴む
3. 基本的な仕組みを理解する

## 28. A-1からA-2/Bへの橋渡し

教材をA-1で完全に閉じない。

例としてTCPでは、

### A-1

```text
TCPとは何か
3-way handshakeとは何か
```

### A-2への橋

```text
SYN Floodはこの仕組みをどう悪用するか
```

### Bへの橋

```text
大量のSYNがログに出ている場合、
何が起きている可能性があるか
```

という流れを意識する。

目的は、

「A-1で仕組みを理解し、その知識をA-2/Bでセキュリティに応用する」

という学習体系を作ること。

## 30. 文章ルール

文章は初学者向けにする。

以下を避ける。

- 長大な説明

- 用語だけを説明する辞書形式

以下を優先する。

- 短い段落
