# 教材UIの設計

## Overview

`SPEC.md`と承認済みのPhase 1設計に従う。情報セキュリティマネジメント合格程度の日本語話者が、PCを中心にスマートフォンでも技術基礎を学ぶ。落ち着いた学習ノートと操作パネルを組み合わせ、操作・重み・結果を結び付ける。販促的なヒーローや過度な装飾を加えない。

## Colors

実行時の値の正本は`css/common.css`の`:root`。ライトは白い教材面と淡い青灰色の背景、ダークは青灰色の暗い背景と明るい文字を使う。ダークの上書きは`:root[data-theme="dark"]`で一元管理する。操作、完了、入力エラーの意味は両モードで揃える。色だけで状態を伝えず、数値・ラベル・記号を併記する。各ページで独自の色を定義しない。

初回は端末の配色設定に合わせ、ヘッダーのダークモード切替で選んだ設定を`riss.a1.theme`に保存する。学習進捗とは別のキーで管理する。本文描画前に`js/theme.js`を実行し、保存した配色を適用する。保存不可でも切替でき、その旨を表示する。

## Typography

日本語本文は`--font-body`でメイリオを優先し、ヒラギノ角ゴシック、Noto Sans JPへフォールバックする。数値・進数・式は`--font-number`でConsolasなどの等幅フォントを使う。本文17px、行間1.8を基本にする。外部フォントを読み込まない。説明はです・ます調、操作は「反映する」「答え合わせ」「学習完了にする」で統一する。

## Layout

最大幅1120px。PCのトップは導入と進捗、2列の章カード。教材はページ内目次と本文。960px以下で目次を上部へ、760px以下でトップを1列へ。bit列は460px以下で上位・下位の4bitずつに分ける。スクロールは文書全体が管理する。

## Elevation & Depth

静的なカードは影を使わず境界線で区切る。Labは青い枠と結果領域で本文から区別する。

## Shapes

パネルは`--radius`、入力とbitは6px、通常ボタンは8px。主要操作は高さ48px以上、bitボタンは56px以上。

## Components

- `common.css`：共通トークン、操作、状態、フォーム、章カード、進捗。
- `lesson.css`：本文、問題、完了操作、前後ナビ。
- `lab.css`：Labの操作領域、重み、結果、レスポンシブ配置。
- 入力する進数はネイティブselect。OSのポップアップと標準のキーボード操作を使用する。
- 教材ID・順序・公開状態は`js/curriculum.js`。本文・目次のリンクは静的HTML。教材追加時は両方を更新する。
- 進捗は`js/progress.js`。形式バージョン1、サイト固有キー、完了と成績を分離する。破損・未知の形式は上書きせずメモリ内で継続する。
- 確認問題は`js/quiz.js`。各問の最初の回答を固定し、全問回答後に直近成績を保存する。再挑戦は成績や完了を直ちに消さない。
- Lab固有の状態・計算は`js/labs/`。入力値全体を検証してから結果を更新する。
- 論理演算・半加算器・Dフリップフロップの動く図はインラインSVG。配線は実線=1、破線=0とし、数値ラベルと文章も必ず併記する。操作にはネイティブHTMLボタンを使う。図はJSから状態を更新し、外部SVGのDOMアクセスやfetchに依存しない。
- 実物に近いハードウェア図はPNGで保存し、レジスタとキャッシュは同じCPU内部の拡大イメージとして示す。写真・リアルな絵にはSVG説明図用の色反転を適用せず、役割をHTMLの説明と代替テキストでも伝える。
- 画像・アイコン素材は`assets/images/`・`assets/icons/`へ保存する。説明用回路図はSVG画像とし、ラスタ画像が適切な場合のみPNGを使う。
- RSラッチLabはOR+NOTで描くNOR型の交差接続。S=Set、R=Reset、上段Q・下段Qバー。入力00で前の値を保持し、11では両出力0、11から同時に00へ戻すと不定を表示する。図は整定後の状態で、伝搬遅延は再現しない。狭い画面の図は文字を縮めず、キーボードで横スクロールできる領域にする。
- フリップフロップLabは立上り型D-FF。Dの変更やClockの立下りではQを保持する。操作順のチャートと表は直近8状態に制限し、実時間を表す図と混同させない。初期Q=0は実験用の仮定であると明記する。

- CPU LabはLOAD・ADD・STORE・HALTの固定プログラムを手動で進める。取出し・解読・実行は教育用の段階で、実CPUのクロック数や命令長を再現しない。PC・IR・ACCと主記憶の値をSVG・表・文章で併記し、入力の反映時に実験を初期化する。CPU Labの主表示は日本語の指示とし、命令名は補足で対応を示す。番地は「場所」、値は「中身の数」と明記し、命令オペランドに裸の数字を表示しない。CPU固有CSSは`cpu.css`に限定する。CPU図のレジスタは横並びにし、図・主記憶・結果・操作を1920×900の表示領域で見渡せる配置にする。数値変更と課題はネイティブdetailsに格納し、補足説明はLab外に残す。結果欄は高さを確保して段階操作時のボタン移動を抑える。狭い画面では縦並びと文書スクロールに戻す。

- キャッシュLabは3つの固定番地を2枠の完全連想キャッシュへコピーする読出しモデル。置換はLRUで、ヒット時も使用順を更新する。確認1単位・ミス時追加9単位・キャッシュなし9単位の教育用時間を明記する。元の主記憶は変更せず、場所と数を図・表・文章で区別する。平均と割合は読出し回数から計算し、未読状態は割り算しない。共通のLabに`memory-cache.css`を追加し、動く図はインラインSVGとする。

## Do's and Don'ts

- 見出し、入力ラベル、キーボード操作、可視フォーカス、読み上げ用状態を保つ。
- 実在するページだけリンクにする。準備中と未学習を区別する。
- 本文をJSやfetchに依存させず、通常のdeferスクリプトと相対パスを使う。
- 初期段階ではビルド、フレームワーク、汎用Labエンジンを導入しない。
- 確認問題の合格やスクロール到達を学習完了の条件にしない。
- JavaScript無効時には操作ボタンを表示せず、本文と静的なLabの例を残す。
